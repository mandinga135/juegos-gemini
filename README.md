# Juegos de lectura sobre Gemini

Cinco juegos de nivel intermedio, basados en el documento «El origen y la evolución de Gemini», para 3.er año.

- Sopa de letras con ocho pistas.
- Crucigrama de ocho conceptos.
- Tres frases encriptadas con cifrado César.
- Ahorcado de historia y ahorcado de criterio, con tres rondas cada uno.

## Cómo jugar

Abrí `index.html` en un navegador. Funciona sin internet y sin instalaciones. Las pistas remiten a las páginas del PDF incluido.

## Respuestas

`respuestas.html` y `Respuestas_Gemini.pdf` contienen las soluciones de todos los juegos.

## Tecnología

HTML, CSS y JavaScript. El progreso se conserva al cambiar de juego dentro de la misma sesión; al recargar se reinicia.
